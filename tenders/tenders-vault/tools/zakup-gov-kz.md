# Инструмент — единая платформа закупок и МЭКС (без ключа)

**Единая платформа закупок** `zakup.gov.kz` (Минфин, «одно окно») показывает лоты сразу четырёх
площадок: госзакуп, Самрук-Қазына, Mitwork, ФСМС. У неё **открытый API — ключ не нужен**
(проверено 2026-11-11 с машины в Казахстане). Скрипт — `engine/scripts/portal.py`.

**МЭКС** — платформа закупок нацпроекта «Модернизация энергетического и коммунального секторов»
(`meks.zakup.sk.kz`, с ноября 2025, коммунальные предприятия: водоканалы, тепло, электросети).
Свой открытый API, ключ не нужен. В единую платформу не входит.

## Что чем брать

| Нужно | Чем |
|---|---|
| новые тендеры: госзакуп, Самрук, Mitwork | `portal.py lots` — без ключа |
| новые тендеры МЭКС | `portal.py meks` — без ключа |
| договоры, победители, участник по БИН, РНП, документы лота | `ows.py` — ключ госзакупа ([[ows-api]]) |

Самрука и Mitwork в API по ключу (`ows.goszakup.gov.kz`) **нет** — только здесь.

## Единая платформа — API

`GET https://zakup.gov.kz/api/core/api/public/lots/?limit=…&offset=…` + фильтры; ответ — `count`, `results`.
Несколько значений одного фильтра — повтором параметра (`status_id=6&status_id=7`), это «или».

| Фильтр | Параметр | Значения |
|---|---|---|
| площадка | `system_id` | 1 госзакуп (ЭГЗ) · 2 Mitwork · 3 Самрук (SKK) · 4 ФСМС |
| текст или номер | `q` | слово |
| предмет | `purchase_subject_id` | 1 товары · 2 работы · 3 услуги |
| статус | `status_id` | приём заявок: 6, 7, 8, 9, 63 — словарь `dicts/lot-statuses/` |
| способ | `purchase_method_id` | словарь `dicts/purchase-methods/` (конкурсы и тендеры — по слову в названии) |
| сумма | `total_price__gte`, `total_price__lte` | ₸ |
| место поставки | `delivery_address_id__in` | id из `dicts/katos/?q=<название>` (Карагандинская область — 9674) |

В лоте: площадка, способ, статус, сумма, заказчик и БИН, место поставки (КАТО), ЕНС ТРУ, даты приёма,
номер объявления.

## МЭКС — API

`GET https://meks.zakup.sk.kz/api/pub/application-announcement-311/list?page=…&size=…` — все конкурсы;
фильтр — на нашей стороне. Поля: `concursNum`, `concursName`, `customerName`/`customerBin`,
`placeProjectImplementationName`, `status` (приём: `PUBLISHED`, `ACCEPTING_APPLICATIONS`,
`APPLICATION_PERIOD_EXTENDED`, `ACCEPTING_COMMENTS_REQUESTS`), `data.procurementTypeCode`
(`works`/`services`), `data.totalSumWithoutNDS`, `data.startDate`/`endDate`.
2026-11-11 вечером площадка отвечала то 200, то **502** — скрипт повторяет запрос, затем сдаётся.

## Монитор «только новые»

`--new <файл>` — файл помнит id показанных лотов; следующий запуск показывает только новые.
Запуск — вручную; по расписанию — когда владелец скажет.

## Правило

Площадка общая: скрипт ждёт между запросами; не гонять в цикле.
